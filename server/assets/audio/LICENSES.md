# Music beds — sources & licenses

Every bed in this folder is **CC0 1.0 (public domain dedication)** — free for
any use, including commercial, with no attribution required. Attribution is
recorded here anyway so provenance is never in doubt.

Both files are 32-second excerpts (128 kbps MP3) trimmed from the original
full-length seamless loops; CC0 permits modification. The video pipeline
loops and fades them under the narration, so an excerpt is all a render
ever needs.

| Shipped file | Original | Artist | Source | License |
|---|---|---|---|---|
| `bed-groove.mp3` (default) | `winaaa_bgm_groove_v1.mp3` | WinAAA | "WinAAA BGM — CC0 background music for talking videos (18 loops)", Internet Archive item `winaaa-bgm-cc0` — https://archive.org/details/winaaa-bgm-cc0 | CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/ |
| `bed-calm.mp3` | `winaaa_bgm_calm_v1.mp3` | WinAAA | same collection as above | CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/ |

The collection is purpose-made background music "to sit under a speaking
voice" (explainers, reviews, vlogs); the item's metadata license field reads
`http://creativecommons.org/publicdomain/zero/1.0/` and its description
states: "CC0 1.0 (public domain dedication): free for any use including
monetised YouTube videos and commercial work, no credit required."

Retrieved 2026-11-11 from
`https://archive.org/download/winaaa-bgm-cc0/<original filename>`.

To use a different bed at runtime, drop a file in this folder and set
`VIDEO_MUSIC_BED=<filename>` — but only add material under the same rule:
CC0 or public domain, with the source documented in this file.
