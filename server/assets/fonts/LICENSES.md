# Bundled fonts (AI Clipper caption burn-in)

The server ships these fonts so ffmpeg/libass can render burned-in captions
identically in every environment (Render has no guaranteed system fonts).

- **ArchivoBlack.ttf** — Archivo Black, © The Archivo Project Authors.
  SIL Open Font License 1.1. Via @expo-google-fonts/archivo-black.
- **LiberationSans-Regular.ttf / LiberationSans-Bold.ttf** — Liberation Sans,
  © Red Hat, Inc. SIL Open Font License 1.1 (metric-compatible with Arial).
